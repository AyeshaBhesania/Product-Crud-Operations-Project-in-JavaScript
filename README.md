# 🍔 Food Product Management Website

## 📌 Project Overview

This project is a food product management website built using **HTML, CSS, and JavaScript**.

The website allows users to manage food products using **CRUD operations (Create, Read, Update, Delete)**. Product information is stored in **Local Storage**, so the data remains available even after refreshing the page.

The project also includes **searching, sorting, and filtering** features to make it easier to find and manage food products.

---

## 🎯 Project Objective

The main objective of this project is to understand and implement:

- JavaScript CRUD operations
- DOM manipulation
- Local Storage
- Form handling and validation
- Dynamic product rendering
- Searching
- Sorting
- Filtering
- Basic user interaction

---

## ✨ Features

### ➕ Create Products
Users can add new food products by entering:

- Food Title
- Price
- Image
- Category

The product is added dynamically to the product list.

### 👀 Read Products
All saved food products are displayed dynamically on the webpage with:

- Food image
- Food title
- Price
- Category
- Edit button
- Delete button

### ✏️ Update Products
Users can edit an existing food product and update its details.

Each product has a unique ID so that the correct product can be edited.

### 🗑️ Delete Products
Users can delete any food product from the list.

The product is removed from both the webpage and Local Storage.

### 💾 Local Storage
Food product data is stored in the browser's Local Storage.

This means the products remain available even after:

- Refreshing the page
- Closing and reopening the browser

### 🔍 Search
Users can search for food products by their title.

### ↕️ Sort
Products can be sorted by price:

- Low to High
- High to Low

### 🏷️ Filter
Users can filter food products based on their category.

Example categories:

- Pizza
- Burger
- Sandwich
- Dessert
- Drinks

### 🧹 Form Reset
After successfully adding a food product, the input fields are automatically cleared.
